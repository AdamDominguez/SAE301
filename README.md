# SAE301
Les étudiants de GEII sont en train de mettre au point un système de ruches connectées avec différentes métriques qui sont stockées : poids, température, humidité, données GPS etc.
Ils souhaiteraient voir s'il serait possible que les étudiants de MMI réalisent :
des graphiques issus de ces données, par exemple sur l'année écoulée,
un système pour que chaque apiculteur enregistré puisse consulter ses propres données et donc :
un système d'authentification,
un système d'administration,
une interface pour que chaque apiculteur puisse enregistrer des données supplémentaires sur le suivi de ses ruches.

Il faudrait que le tout soit ergonomique et esthétique, notamment avec une page d'accueil "vendeuse" expliquant un peu tout le projet.
Il faut aussi noter que la communauté des apiculteurs est plutôt âgée, il faut donc penser les interfaces en conséquence.
Les graphiques peuvent être réalisés à l’aide de librairies.
J'ai alors pensé qu'il pourrait être intéressant de lier ces deux SAE pour réaliser ce projet.
Le but étant de pouvoir proposer ces réalisations gratuitement aux apiculteurs du coin.
